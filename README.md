# Swiggy Data Cleaning using Python

## 📌 Overview

This project focuses on cleaning and preprocessing a messy Swiggy dataset using **Python, Pandas, and NumPy**.

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Jupyter Notebook

## 🧹 Data Cleaning Performed

* Handled missing values
* Removed extra whitespace
* Standardized categorical values
* Cleaned dates and currency values
* Validated age, ratings, quantity, distance, and delivery time
* Corrected `TotalAmount`
* Removed duplicate records
* Saved the cleaned dataset

## 📂 Files

* `Swiggy_Data_Cleaning.ipynb` – Data cleaning code
* `Swiggy_Python_Messy_500.csv` – Original dataset
* `Swiggy_Python_Cleaned_500.csv` – Cleaned dataset

## 🎯 Outcome

Converted a messy dataset into a **clean and analysis-ready dataset** using Python.
